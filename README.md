# Calculadora de Intereses — Artigas Abogados

Calculadora **estática** (una sola página `index.html`) optimizada para **GitHub Pages**.
Liquidación de intereses **legal** (art. 1108 CC), **procesal** (art. 576 LEC), **art. 20 LCS**
y **demora comercial** (Ley 3/2004), con imputación de pagos (art. 1173 CC) y exportación a
Word e impresión/PDF.

## Demo (GitHub Pages)
1. Sube `index.html` a un nuevo repositorio.
2. Activa **Settings → Pages → Deploy from a branch → main / (root)**.
3. La calculadora quedará accesible públicamente.

## Uso local
Abre `index.html` en tu navegador (doble clic). No requiere servidor ni dependencias.
